# English dictionary (en.txt)

Definitions come from the **English Wiktionary**
(https://en.wiktionary.org/), extracted with
[wiktextract](https://github.com/tatuylonen/wiktextract) and distributed by
[kaikki.org](https://kaikki.org/dictionary/English/).

- **Content license:** CC BY-SA and GFDL
  (https://en.wiktionary.org/wiki/Wiktionary:Copyrights).
- **Word selection:** frequency list from
  [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords)
  (OpenSubtitles), MIT license.

Generated with `tools/generar-diccionarios/generar_diccionarios.py`.

> Note: this `.md` lives next to the `.txt` on purpose. The loader only processes
> `*.txt` files, so it does not interfere with dictionary loading.
